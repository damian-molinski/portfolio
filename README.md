# portfolio

Personal static portfolio site, built with [Jaspr](https://docs.jaspr.site).

## Stack

- **Dart** `^3.10.0`
- **Jaspr** `0.23.4` in `static` mode — pages are pre-rendered to HTML at build time, and components
  annotated `@client` are hydrated in the browser.
- **jaspr_lints** `^0.7.2`, loaded through the analyzer plugin system (`plugins:` in
  `analysis_options.yaml`), on top of `package:lints/recommended.yaml`.

## Prerequisites

The Jaspr CLI is a global activation, not a dev dependency:

```bash
dart pub global activate jaspr_cli
dart pub get
```

## Commands

| Command | What it does |
| --- | --- |
| `jaspr serve` | Dev server on `http://localhost:8080`, with the builder in watch mode. |
| `jaspr build` | Static build; output lands in `build/jaspr/`. |
| `dart analyze` | Analyzer, including the `jaspr_lints` diagnostics. |
| `dart format .` | 120-column page width, `trailing_commas: preserve` — both configured in `analysis_options.yaml`. |

## Layout

| Path | Role |
| --- | --- |
| `lib/main.server.dart` | Server entrypoint. Runs only during pre-rendering; declares the `Document` root. |
| `lib/main.client.dart` | Client entrypoint. Runs in the browser and mounts `ClientApp`. |
| `lib/main.*.options.dart` | Generated by `jaspr_builder`. Do not edit by hand. |
| `lib/app.dart` | The root component: skip link, header, `<main>` with the six sections, footer. Not `@client` — see below. |
| `lib/sections/` | One file per region of the page: header, hero, signals dock, pillars, skills, projects, contact, footer. |
| `lib/components/` | Everything more than one section uses — the section shell, cards, buttons, tag pills, status dots, the icon set. |
| `lib/content/site_content.dart` | Every user-visible string, as typed `const` data. Nothing else declares copy. |
| `lib/constants/theme.dart` | The `DESIGN.md` tokens as Dart, plus the global CSS declared via `@css`. |
| `web/` | Static assets copied into the build: favicon, PWA icons and manifest, the emblem. |
| `docs/reference/` | The frozen render of the design the site was built from, with a README recording where it came from and where it is now wrong. |

Two components are annotated `@client` and are the only JavaScript on the page: `CopyEmailButton`
and `ContactForm`. Everything else — the ambient glow, the entrance animations, every hover and
focus treatment — is CSS. Annotating `app.dart` instead would compile the whole page to JavaScript.

**A `@client` component must have an unnamed constructor.** Jaspr's hydration codegen rebuilds it by
calling one, and `dart analyze` does not catch a named-only constructor — only `jaspr build` does,
and only once the component is mounted.

## Design system

`DESIGN.md` is the source of truth for colour roles, the type scale, spacing tokens and component specs.
Its YAML frontmatter holds the token values; the prose beneath it describes the intent behind them. Read it
before adding UI.

`lib/constants/theme.dart` now declares those tokens — `AppColors`, `AppType`, `AppSpacing`,
`AppRadius`, `AppBreakpoints` — so UI code takes them from there rather than restating hex values.
Translucent variants come from the `Color.alpha()` extension in the same file.

`docs/reference/landing-page.html` is the design as it was rendered, kept for layout and spacing.
Do not take colours from it: its Tailwind config overrides the frontmatter with a darker surface
ramp, and `DESIGN.md`'s frontmatter is what this site is built on.

## Status

**The site deploys on every push to `main`**, through `.github/workflows/ci.yml`: one `check` job
runs `just check`, `just markers` and `just build`, and a `deploy` job — which cannot run unless
`check` passed — uploads the pre-rendered output and `functions/` to Cloudflare Pages by direct
upload, then asserts that `/api/contact` is actually routed before calling it good. Pull requests
run `check` alone and deploy nothing.

The marker gate still stands. This must return nothing, and CI fails the branch when it does not:

```bash
grep -rn '\[\[TODO:' lib/
```

Still open: the header's avatar slot renders a literal `?` placeholder
(`ChromeContent.avatarPlaceholder`) because there is no portrait for it yet.
